# Bubble & Fizz — Luxury Mobile Bartending

Professional, licensed & insured mobile bartending service in North Carolina. Mercedes Pettiford brings luxury champagne bars and craft cocktails to weddings, corporate events, and private celebrations.

## Tech Stack

- **React 19** + TypeScript
- **Vite** build tool
- **Tailwind CSS** v3 with custom luxury theme
- **GSAP** with ScrollTrigger for scroll-linked animations
- **Lucide React** for icons

## Development

```bash
npm install      # install dependencies
npm run dev      # start dev server
npm run build    # build for production
npm run lint     # run linter
```
